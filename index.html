Python 刚才怎样算的？

  1. json.load 读取上面的文件，得到 6 条记录。
  2. 逐条检查 0 <= days_ago < 7；表格中标“纳入”的 4 条留下，其余排除。
  3. Counter 按告警类型计数；len(selected) 得到总数。

这是 main.py 中读取与统计的代码：

def load_events():
    with EVENTS_FILE.open(encoding="utf-8") as file:
        return json.load(file)

def count_alerts(events, range_days):
    selected = [event for event in events if 0 <= event["days_ago"] < range_days]
    by_type = Counter(event["type"] for event in selected)
    return {
        "range_days": range_days,
        "total": len(selected),
        "by_type": dict(sorted(by_type.items())),
        "selected_ids": [event["id"] for event in selected],
    }

events：由 6 条记录组成的列表；event 是其中一条记录。 selected：留下符合天数范围的记录。 by_type：分别数“跌倒、设备离线”等类型。 total：留下多少条，告警总数就是多少。

{range_days}、{total}、{by_type} 是留给程序填写的空位。PROMPT_TEMPLATE.format(...) 会把它们换成“7 天、4 次、跌倒 2 次”等实际统计。

程序还会附上一句总规则：正在读取…

  1. 组装：Python 先算次数，再用模板生成上方完整 Prompt；模型不负责数原始记录。
  2. 发送：Python 把总规则和填好数据的 Prompt 作为两条消息，通过 DeepSeek API 发给模型。
  3. 接收与核对：模型返回文字后，页面显示回复；仍要对照第 2 步的次数检查，Prompt 本身不能保证它绝不出错。
